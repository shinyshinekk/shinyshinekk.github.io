# SHINE KIM — Personal Portfolio

A bilingual (English/Korean), responsive portfolio website for Shine Kim, built with HTML, CSS, and vanilla JavaScript.

## Run locally

Open `index.html` in your browser. No build step or API keys are needed. You can also run `python3 -m http.server 8000` in this folder and visit `http://localhost:8000`.

## Publish with GitHub Pages

1. Sign in to GitHub as **shinyshinekk**.
2. Create a **public** repository named **`shinyshinekk.github.io`** (exact spelling). If one already exists, use that repository instead.
3. Upload **all the contents of this folder** to the root of that repository (including `index.html`, `css`, `js`, and `images`). Do not upload the parent folder as an extra nested level.
4. Commit the files to the `main` branch.
5. Go to **Settings → Pages → Build and deployment**, choose **Deploy from a branch**, select **main** and **/(root)**, and save.
6. Wait for the Pages deployment to complete, then visit **https://shinyshinekk.github.io**.
7. For class submission, edit the instructor's `2026-fall/MEMBERS.md`, add your website link under your team, and create a pull request according to the course slides.

## Customize

- **Content and translations:** `js/main.js` (both `copy` and `projectDetails`).
- **Colors and layout:** `css/style.css` (`:root` contains the brand palette).
- **Profile photo:** Replace `images/shine-speaking.jpg` with a new image using the same filename or update the `<img>` tag in `index.html`.
- **GitHub link:** `https://github.com/shinyshinekk` in `index.html`.
